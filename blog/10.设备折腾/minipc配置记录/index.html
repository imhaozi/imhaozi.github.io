      Mini主机折腾日记

      2026-09-10

      背景：有一台 Intel 的小主机

      • U7-255H
      • 内存16G
      • 硬盘4T

      1. Ubuntu系统安装

      1. 从Ubuntu官网下载了Ubuntu22.04的官方镜像，并且用 Rufus制作了启动盘。
      2. 插入U盘，开机按 F2进入 BIOS
        1. 关闭 Secure Boot
        2. 设置 U 盘为第一启动项
      3. 重启后进入安装流程，硬盘分区步骤选择自定义存储布局，磁盘名应该是/dev/nvme0n1
        1. 将硬盘全部清空成一块空闲空间
        2. 依次点 Add GPT Partition，逐个创建 5 个分区（预留的非必须）
      序号分区大小（Size）格式（Format）挂载点（Mount）备注
      1512MBEFI—UEFI 引导分区
      21024MB（1GB）ext4/boot内核和引导文件
      38192M（8GB）swap—交换分区
      4524288M（512GB）ext4/系统根分区（约500G）
      5524288M（512GB）ext4—预留（新系统或系统扩容）
      6剩余全部ext4/data数据分区
      1. 正常安装完进入系统，使用如下命令查看分区
      # 查看分区情况
lsblk
# 查看挂载情况
df -h

# 应该差不多时这样的
NAME          SIZE MOUNTPOINT
nvme0n1       3.7T
├─nvme0n1p1   512M /boot/efi
├─nvme0n1p2     1G /boot
├─nvme0n1p3     8G [SWAP]
├─nvme0n1p4   490G /
└─nvme0n1p5   3.2T /data

# 让当前用户可以自由读写 /data
sudo chown -R $USER:$USER /data

      安装完成后选择重启，重启时界面弹出拔掉引导盘时，拔掉然后正常进入系统即可。

      必要服务安装

      sudo apt update
# 安装网络工具
sudo apt install net-tools
# 安装 SSH 服务
sudo apt install openssh-server -y
# 启动并设置开机自启
sudo systemctl start ssh
sudo systemctl enable ssh
# 配置防火墙放行 SSH
sudo ufw allow ssh
sudo ufw reload
# 重启ssh服务
sudo systemctl restart ssh

      2. 实时内核安装

      目前看，作为工作机的话，两种方式都多少有点问题。

      • 社区版：内核版本比较低，但是工业使用的话其实好像也没什么大问题
      • 源码编译：显示驱动有问题，只能用CPU显示，性能上感觉不好

      2.1 社区版

      此版本安装简单，使用上也没啥大问题。我这里只是使用的WIFI网卡是RTL8851BE，这个版本内核不支持。如果换个网卡或者用不着这个WIFI，社区版系统也是可以的。

      Ubuntu 22.04 的实时内核可以直接从 Universe 仓库获取（社区维护版本），不需要 Ubuntu Pro：

      sudo add-apt-repository universe
sudo apt update
sudo apt install ubuntu-realtime

      修改启动配置

      sudo vim /etc/default/grub

# 第一行数字修改为saved 第二行需手动添加
GRUB_DEFAULT=saved
GRUB_SAVEDEFAULT=true

# 把这两行参数改成如下 通过菜单选择 超时时间10秒
GRUB_TIMEOUT_STYLE=menu
GRUB_TIMEOUT=10

      完成后重新加载

      sudo update-grub

      然后重启，重启时会弹出10秒的选择，进入系统后，后续再启动如果不选择都会默认使用当前这次选择的系统。

      2.2 源码编译

      也可以自己编译实时内核，官网提供了源码，网址：https://www.kernel.org/pub/linux/kernel/projects/rt/6.8/

      这里测试6.8的版本，测试界面会比较卡顿 GPU显示有问题

      安装编译依赖

      sudo apt update
sudo apt install -y build-essential libncurses-dev bison flex libssl-dev libelf-dev \
  dwarves zstd dkms libudev-dev libpci-dev libiberty-dev autoconf fakeroot \
  kernel-wedge cpio

      下载内核源码和 RT 补丁

      mkdir ~/rt-kernel && cd ~/rt-kernel

# 下载内核源码（以 6.8.2 为例，请根据实际可用补丁版本调整）
wget https://mirrors.edge.kernel.org/pub/linux/kernel/v6.x/linux-6.8.2.tar.xz

# 下载对应的 RT 补丁
wget https://cdn.kernel.org/pub/linux/kernel/projects/rt/6.8/patch-6.8.2-rt11.patch.xz

      解压打补丁

      tar -xf linux-6.8.2.tar.xz
xz -d patch-6.8.2-rt11.patch.xz

cd linux-6.8.2

# 先 dry-run 检查补丁是否能正常应用
patch -p1 --dry-run < ../patch-6.8.2-rt11.patch

# 确认无报错后，正式打补丁
patch -p1 < ../patch-6.8.2-rt11.patch

      配置

      # 复制当前系统内核配置作为基础
cp -v /boot/config-$(uname -r) .config

# 先做一次旧配置适配
make olddefconfig

# 进入图形化配置界面
make menuconfig

# 配置1 General setup ---> Preemption Model ---> Fully Preemptible Kernel (Real-Time)
# 配置2 Processor type and features ---> Timer frequency (1000 HZ)
# 其他配置根据自己需求搜 这里没别的特殊的

      编译

      # 使用所有 CPU 核心编译，生成 .deb 安装包
make -j$(nproc) bindeb-pkg

# 我这里遇到了证书相关报错 解决方法
cd ~/rt-kernel/linux-6.8.2
scripts/config --disable SYSTEM_TRUSTED_KEYS
scripts/config --disable SYSTEM_REVOCATION_KEYS
scripts/config --disable MODULE_SIG
scripts/config --disable MODULE_SIG_ALL
scripts/config --disable MODULE_SIG_KEY
scripts/config --disable INTEGRITY_PLATFORM_KEYRING
# 然后重新编译

      安装

      cd ~/rt-kernel

haozi@Ubuntu22:~/rt-kernel$ ls
linux-6.8.2         linux-headers-6.8.2-rt11_6.8.2-3_amd64.deb  linux-image-6.8.2-rt11-dbg_6.8.2-3_amd64.deb  linux-upstream_6.8.2-3_amd64.buildinfo  patch-6.8.2-rt11.patch
linux-6.8.2.tar.xz  linux-image-6.8.2-rt11_6.8.2-3_amd64.deb    linux-libc-dev_6.8.2-3_amd64.deb              linux-upstream_6.8.2-3_amd64.changes

haozi@Ubuntu22:~/rt-kernel$ sudo dpkg -i linux-image-6.8.2-rt11_6.8.2-3_amd64.deb linux-headers-6.8.2-rt11_6.8.2-3_amd64.deb

      修改启动配置

      sudo vim /etc/default/grub

# 第一行数字修改为saved 第二行需手动添加
GRUB_DEFAULT=saved
GRUB_SAVEDEFAULT=true

# 把这两行参数改成如下 通过菜单选择 超时时间10秒
GRUB_TIMEOUT_STYLE=menu
GRUB_TIMEOUT=10

      更新重启

      sudo update-grub
sudo reboot

      2.3 测试验证

      验证系统内核

      uname -r

# 非实时系统正常应该是6.x
# 实时系统应该是带有 realtime 字样，社区版是 5.15.0-1032-realtime

      测试实时性

      # 安装测试工具
sudo apt install rt-tests
# 测试命令
sudo cyclictest -l 100000 -m -S -p 90 -i 200 -h 400

-l 100000：循环 10 万次
-m：锁定内存，防止页面换出引入延迟
-S：SMP 模式下统一所有线程参数
-p 90：实时线程优先级设为 90
-i 200：每 200 微秒唤醒一次
-h 400：统计 400 微秒以内的延迟直方图
